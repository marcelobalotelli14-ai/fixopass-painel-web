Integração ERP

Configure como seu sistema recebe os dados assim que o cliente aprova.

Webhook

Sempre que um cliente aprovar um compartilhamento, o FIXO PASS envia os dados automaticamente pra essa URL via POST. Deixe em branco se seu ERP vai consultar o status manualmente (polling).

Consulta manual de status (polling)

Se preferir não usar webhook, seu ERP pode consultar o status de uma solicitação diretamente:
GET http://localhost:3000/auth/request/<solicitacaoId>
Header: X-API-KEY: <sua API Key>

API Key
